## 🌟 Key Highlights & Architecture

- **Interactive 3D Workstation:** Built with Three.js, `@react-three/fiber`, and `@react-three/drei`.
- **Realistic Biological Snake Walk:** Dynamic sinusoidal locomotion canvas with real-time yaw rotation and pulsing energy head traveling down the work experience spine.
- **Deep Navy Dark Theme:** Immersive `#050816` space theme with dual-density multi-colored starfield particles (Cyan, Blue, Pink, Purple).
- **Verified Credentials:** 8 verified professional certifications with interactive credential viewing and PDF certificates.
- **Project Showcase:** Interactive project cards with live demo links and GitHub source code repositories.
- **Interactive 3D Earth Globe & Contact Form:** Seamless message dispatch powered by EmailJS.

## 📜 Setup & Local Development

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/swarajpakhale/swarajpakhale.github.io.git

# Navigate to project directory
cd swarajpakhale.github.io

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Compile and optimize production bundle
npm run build

# Preview production build locally
npm run preview
```

### GitHub Pages Deployment
```bash
# Deploy to GitHub Pages (gh-pages branch)
npm run deploy
```
